A Note About Processing Fees

Every online transaction involves a payment processor. We use Stripe — the same processor used by Shopify, Amazon, and thousands of other platforms. Stripe charges approximately 2.9% + $0.30 per transaction. This is an industry-standard fee charged by Stripe directly — not by Aequitas Market.
